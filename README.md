# volleyball

**Homepage:** open **`index.html`** for links to all prototypes (works on **GitHub Pages** from repo root).

**Coach's Corner:** **`coaches-corner.html`** — **drill library** (filter by skill/level, incl. **game-pressure** drills) with a **pressure scenario dealer + scoreboard** for tight-game scrimmages, **plyometrics** (32-exercise library across landing, vertical, horizontal, lateral, single-leg, reactive/depth, and upper-body + a **session builder** by level, season phase, and focus with foot-contact budgets), **team strategies** (offense systems, serve receive, defense, blocking, serving, attack), and a **matchup planner**: rate each position **strong / neutral / weak** for your team and the opponent to get a game plan (where to set, who to serve, blocking/defense, lineup), plus a **situational playbook** for in-match adjustments.

**Tactical board (app):** **`tactical-board/`** — interactive **3D play visualizer**: drag team silhouettes, edit ball Bézier arcs, timeline scrub/playback, camera presets, JSON + URL hash share. See **`tactical-board/README.md`**.

3D direction: **Three.js** prototypes and plan live under:

- **`docs/THREE_JS_PLAN.md`** — roadmap and stack notes  
- **`prototypes/03-standard-volleyball-court.html`** — **FIVB-scale** 18×9 m court, **neon night** palette (black void + cyan / magenta / lime / violet lines)  
- **`prototypes/01-court-scene.html`** — stylized court, same neon-night vibe  
- **`prototypes/02-ball-arc.html`** — serve arc + replay, neon trail + net glow  
- **`prototypes/04-player-positions.html`** — twelve stylized players, **USAV court zones Z1–Z6** (RB/RF/MF/LF/LB/MB), **CSS2D** labels, 3 formations  
- **`prototypes/05-outside-hitter-defense.html`** — **perimeter vs rotational** D vs OH, animated shifts, distinct roles, **responsibility rings**, **attack cone + wedge + arc**  
- **`prototypes/06-attack-sets.html`** — **net zones 1–9** reference, call-sheet sets (1, 31, 2, 3, Rip, Shoot, 4/Hut, 5, 9, A, Slide, Pipe, Bic, 30/Pink, 10, D, dump), quadratic + cubic slide, optional ball animation  
- **`prototypes/07-outside-hitter-approach.html`** — setter **5 / 4 / Shoot** to left pin; OH starts **outside the sideline** with **both feet** (L/R) driving a stylized spike approach in sync with the ball; **slow playback**; coaching on **reads**, **footwork**, **patterns**  
- **`prototypes/08-basic-drills.html`** — **fundamental drills** library: pepper progression, wall ball, serving targets, passing ladder, solo toss–pass–set vs wall; **checklists** + **3D targets** + optional **ball motion**  
- **`prototypes/09-setter-footwork.html`** — **setter footwork** for serve-receive / first ball: **in-system**, **tight**, **off-net chase**, **inside seam**, **wide pin**; stylized **L/R feet**, **ball arc**, phase HUD, **~step counts**, coaching copy  

Open **`index.html`** or any prototype in a browser (needs network for the Three.js CDN).
